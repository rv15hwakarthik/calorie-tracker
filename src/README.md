# src/

Application code lives here. Expo Router screens stay in `app/` at the repo root.

- `components/` — reusable UI
- `features/` — auth, onboarding, dashboard, profile (API + hooks per domain)
- `lib/` — supabase client, macros, date helpers
- `stores/` — Zustand stores
- `types/` — Supabase-generated DB types (Module 2)
